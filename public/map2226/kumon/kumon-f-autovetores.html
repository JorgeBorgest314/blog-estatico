Testar se v é autovetor

Calcule Av. Se o resultado for um múltiplo de v, então v é autovetor e o múltiplo é o autovalor λ.

Exemplo
211211 = 33 = 311 → sim, λ = 3.    211210 = 21 → não é múltiplo de 10.
Dica
Autovetor: Av = λv, com v ≠ 0. O mesmo λ tem de servir nas duas coordenadas. Se uma coordenada de v é 0, a mesma coordenada de Av também tem de ser 0. Resultado (0, 0) conta: é 0 vezes v.

Uma solução não nula de uma equação

Escreva um vetor (x, y) ≠ (0, 0) que satisfaça a equação. Use os menores inteiros possíveis.

Exemplo
3x + 2y = 0: troque os coeficientes e mude um sinal → (x, y) = (2, −3). Conferindo: 3·2 + 2·(−3) = 0. ✓
Dica
Para ax + by = 0 sempre serve (b, −a). Depois simplifique: (2, 2) vira (1, 1). Qualquer múltiplo não nulo também é resposta certa. Se só aparece y, então y = 0 e x é livre.

Núcleo de uma matriz com determinante zero

Ache um vetor v ≠ 0 tal que a matriz vezes v dê o vetor nulo.

Exemplo
2−4−12xy = 00: a 1ª linha dá 2x − 4y = 0 → v = 21. A 2ª linha, −x + 2y = 0, dá a mesma condição.
Dica
Com det = 0 as duas linhas são proporcionais: dizem a mesma coisa. Use uma só linha (que não seja nula) e resolva como na folha F2. Confira multiplicando a matriz por v.

Autovalor repetido: quantos autovetores?

O autovalor λ é repetido. Monte A − λI e diga a dimensão do núcleo (1 ou 2) e se A é diagonalizável.

Exemplo
3003, λ = 3: A − 3I = 0000 → dim = 2, diagonalizável.
3013, λ = 3: A − 3I = 0010 → dim = 1, não diagonalizável.
Dica
Matriz nula: núcleo é o plano todo (dim 2). Matriz não nula com det = 0: núcleo é uma reta (dim 1). Diagonalizável ⟺ existem 2 autovetores independentes.

Autovalores, autovetores e a matriz P

Ache os dois autovalores (folha E5), um autovetor de cada e monte P com os autovetores nas colunas, na mesma ordem dos autovalores.

Exemplo
A = 2003: λ1 = 3, v1 = 01;  λ2 = 2, v2 = 10;  P = 0110.
Dica
Ordem do procedimento: tr e det → λ1, λ2 → A − λI para cada um → v1, v2. Escreva o maior autovalor primeiro. Autovalores distintos dão autovetores independentes, então P tem inversa.
