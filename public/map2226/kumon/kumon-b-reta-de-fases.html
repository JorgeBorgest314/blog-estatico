Sinal de N′ em um ponto

Substitua o valor de N no lado direito e escreva só o sinal de N′: +, − ou 0.

Exemplo
N′ = N − 4, com N = 6  →  6 − 4 = 2  →  sinal +.
N′ = N(N − 3), com N = 1  →  (+) · (−)  →  sinal −.
Dica
Não é preciso o valor exato, só o sinal. Em um produto, descubra o sinal de cada fator: (+)·(+) = +, (+)·(−) = −, (−)·(−) = +.

Sinal em cada lado do equilíbrio

Ache o equilíbrio N*. Depois escolha um ponto de teste de cada lado e escreva o sinal de N′.

Exemplo
N′ = N − 4  →  N* = 4.
Lado N < 4: teste N = 0 → 0 − 4 < 0 → sinal −.
Lado N > 4: teste N = 5 → 5 − 4 > 0 → sinal +.
Dica
O sinal de N′ só pode mudar em um equilíbrio. Por isso um ponto de teste de cada lado basta. Escolha pontos fáceis (0, ou um número redondo).

Do sinal à seta

Desenhe uma seta em cada caixa da reta de fases: → se N′ > 0, ← se N′ < 0. Nos itens 7 a 10, escreva também N* no círculo.

Exemplo
N′ = N − 4, N* = 4. À esquerda de 4 o sinal é −; à direita é +.
←4→
Dica
A reta é o eixo de N, crescendo para a direita. N′ > 0 significa N aumentando: seta →. N′ < 0 significa N diminuindo: seta ←. Use os sinais da folha B2.

Exemplo
N′ = N(1 − N10), N(0) = 3. Reta: ←0→10←3 está entre 0 e 10, onde a seta é →: N(t) cresce e tende a 10.
Dica
Localize N(0) na reta e siga a seta até o próximo equilíbrio: a solução nunca o atravessa. Sem equilíbrio no caminho, ela se afasta sem limite. Se N(0) é um equilíbrio, fica parada.
