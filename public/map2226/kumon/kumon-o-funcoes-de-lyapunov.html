Condição (i): V é positiva fora da origem?

A condição (i) pede V ≥ 0 e V = 0 só na origem. Responda sim ou não; se não, dê um ponto diferente da origem em que V ≤ 0.

Exemplo
V = x2 + 3y2: soma de quadrados que só se anula com x = 0 e y = 0 → sim.  V = y2: no ponto (1, 0) vale 0 → não, falha em (1, 0).
Dica
Potências pares com coeficientes positivos nunca são negativas. O perigo é V se anular fora da origem: isso acontece quando falta uma variável, quando o quadrado é de uma combinação como x − y, ou quando V é um produto como x2y2. Um termo com sinal de menos, ou um produto xy, pode deixar V negativa: teste um ponto.

O sinal de V̇

Escreva < 0 se V̇ é negativa em todo ponto fora da origem; ≤ 0 se nunca é positiva mas se anula fora da origem (diga onde); falha se é positiva em algum ponto (dê um).

Exemplo
V̇ = −x2 − 5y2 → < 0.  V̇ = −3x2 → ≤ 0, anula-se no eixo y.  V̇ = x2 − 4y2 → falha: em (1, 0) vale 1.
Dica
É a folha O1 com o sinal trocado: agora quer-se V̇ negativa. “< 0” é o critério que garante função de Lyapunov estrita; “≤ 0” garante função de Lyapunov, mas não garante estrita. V̇ = 0 em todo ponto conta como “≤ 0”.

Exemplo
V = x2(x + 4): anula-se em x = 0 e x = −4. Como x2 ≥ 0, o sinal é o de (x + 4): positivo para x > −4.  W = {x > −4}.
Dica
