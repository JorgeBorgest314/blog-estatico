N = A − λI e a dimensão do núcleo

Subtraia λ da diagonal e diga a dimensão do núcleo de N: 3 menos o número de linhas independentes.

Exemplo
A = 211121112, λ = 1: N = 111111111. As três linhas são iguais: 1 linha independente → dim ker N = 2.
Dica
N nula: dim 3. Todas as linhas múltiplas de uma só: dim 2. Duas linhas independentes (a terceira é combinação delas): dim 1. Como λ é autovalor, det N = 0 e nunca há três independentes. A dimensão do núcleo é o número de blocos de Jordan de λ.

O quadrado N2

Calcule N2 = NN: entrada (linha i, coluna j) = linha i de N vezes coluna j de N.

Exemplo
N = 000200030:  N2 = 000000600. Só a entrada (3, 1) sobra: 3 · 2 = 6.
Dica
É a folha D2 com três parcelas por entrada. Com autovalor triplo, N3 = 0 sempre. Se N ≠ 0 e N2 = 0, o maior bloco de Jordan tem tamanho 2; se N2 ≠ 0, há um bloco de tamanho 3. No item 6 o autovalor é só duplo, e N2 não tem por que se anular.
