Parte real a e parte imaginária b

Os autovalores são complexos: λ = a ± bi. Calcule a = tr/2 e b = √(det − a2), com b > 0.

Exemplo
tr = 2, det = 5:  a = 1,  b = √(5 − 1) = 2  →  λ = 1 ± 2i.
Dica
É a folha E4 por outro caminho: soma dos autovalores = 2a = tr; produto = a2 + b2 = det. Se det − a2 der negativo ou zero, os autovalores não são complexos.

A exponencial etA

Use etA = eat(cos bt · I + sen bt · M/b).

Exemplo
a = 1, b = 2, M = 2−42−2:  M/b = 1−21−1 → etA = etcos 2t + sen 2t−2 sen 2tsen 2tcos 2t − sen 2t.
Dica
