Sistema desacoplado: solução geral

Cada equação só envolve a sua própria variável. Resolva cada uma separadamente (folha C1).

Exemplo
x′ = 2x,  y′ = −5y  →  x(t) = C1e2t,  y(t) = C2e−5t.
Dica
São duas equações de Malthus lado a lado. Use constantes diferentes, C1 e C2: uma não tem relação com a outra. Se a equação é y′ = 0, então y é constante: y(t) = C2.

Ache C1 e C2 pelas condições iniciais e escreva a solução do PVI (folha C2).

A exponencial etD de uma matriz diagonal

Escreva a matriz etD: troque cada entrada da diagonal λ por eλt.

Exemplo
D = 200−5  →  etD = e2t00e−5t.
Dica
Só a diagonal vira exponencial; os zeros fora da diagonal continuam zeros (não viram e0 = 1). Entrada 0 na diagonal vira e0 = 1. Essa regra só vale para matriz diagonal.

Para onde vai a solução quando t → +∞

Olhe o sinal de cada autovalor e diga o limite de cada coordenada. Depois classifique a origem: nó estável, nó instável, sela ou degenerado.

Exemplo
D = −1002, X(0) = 34:  x = 3e−t → 0,  y = 4e2t → +∞. Sinais opostos: sela.

G5 · Limite quando t → +∞

1. x → 0, y → 0 · nó estável
2. x → +∞, y → +∞ · nó instável
3. x → +∞, y → 0 · sela
4. x fica em 0, y → 0 · sela
5. x → +∞, y fica em 0 · sela
6. x → 0, y → 0 · nó estável
7. x → 0, y → −∞ · sela
8. x → +∞, y fica em 2 · degenerado
“Fica em 0” quer dizer que a coordenada é constante (o limite é esse valor). Itens 3, 4 e 5: mesma sela, três pontos iniciais. Só quem começa no eixo y (item 4) vai para a origem; os outros escapam. Por isso a sela é instável. Item 6: os dois autovalores iguais (nó estrela). Item 8: y não se move; os equilíbrios formam a reta x = 0.
